This folder contains Python-based assignments organized by task number.

- `GenAI-Assignment2-DimpiKalita/`

## How to navigate

1. Open the `GenAI-Assignment2-DimpiKalita/` folder first.
2. Open the `GenAI-TaskN/` folder for the specific task.
3. Each task folder typically contains a Jupyter notebook (`*.ipynb`) with the implementation and a text file (`TaskN.txt`) with the task notes.

## Notes

- The notebooks are the main working files and can be opened directly in VS Code or Jupyter.
- The `TaskN.txt` files provide the task description and can be used as a quick reference.
