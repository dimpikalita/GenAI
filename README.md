## How to navigate

1. Open the `Python/` folder first.
2. Choose the assignment folder you want to review, either `GenAI-Assignment1-DimpiKalita/` or `GenAI-Assignment2-DimpiKalita/`.
3. Inside each assignment folder, open the `GenAI-TaskN/` folder for the specific task.
4. Each task folder typically contains a Jupyter notebook (`*.ipynb`) with the implementation and a text file (`TaskN.txt`) with the task prompt or notes.

## Notes

- The notebooks are the main working files and can be opened directly in VS Code or Jupyter.
- The `TaskN.txt` files provide the task description and can be used as a quick reference.
- A Python virtual environment exists in `.venv/` at the repository root for dependency isolation.
